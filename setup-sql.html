1. 삼기연

회계 관리 (3·1 만세길 걷기는 삼일만세운동본부 칸에 있습니다)

  1. 아래 단추로 복사
  2. Supabase 삼기연 프로젝트의 SQL Editor 열기 (로그인 필요) SQL Editor 열기 ↗
  3. Supabase 화면 맨 위 프로젝트 이름이 samgoe-cc 인지 확인한 뒤, 편집 칸을 길게 눌러 붙여넣기 → 오른쪽 아래 Run
    결과 창에 장부 기록 (처음엔 0) 한 줄이 나오면 성공

2. 삼일만세운동본부

새 manse 프로젝트 전체 설치 — 회원 · 임원 명단 · 공문/자료 · 활동 기록/사진/영상 · 3·1 만세길 걷기(회차 · 신청 · 행운권 QR · 경품) · 걷기 결과 보고 · 언론 보도 · 회계 (한 번에)

  1. 아래 단추로 복사
  2. manse 프로젝트의 SQL Editor 열기 → 맨 위 프로젝트 이름이 manse 인지 확인 (samgoe-cc 이면 안 됩니다) → 붙여넣기 → Run manse SQL Editor 열기 ↗ 결과 창에 장부 기록 (처음엔 0) 한 줄이 나오면 성공
  3. manse 프로젝트 왼쪽 Authentication 에서 두 가지 (처음 한 번)
    ① Sign In / Providers → Email 의 Confirm email 끄기 → Save (가입하면 바로 로그인되게) ① 이메일 가입 설정 열기 ↗ ② URL Configuration 의 Site URL 에 https://samgoe-cc.or.kr/manse/, Redirect URLs 에 https://samgoe-cc.or.kr/manse/** 넣고 Save (비밀번호 찾기 메일용) ② 주소 설정 열기 ↗

다른 프로젝트에서 실행하면 "이 SQL은 ○○ 프로젝트에서 실행해야 합니다"라고 나오고 아무것도 바뀌지 않습니다. 프로젝트를 바꿔 다시 실행하면 됩니다.
붙여넣기가 잘 안 되면: 복사 단추 아래에 나오는 글 상자를 길게 눌러 전체 선택 → 복사한 뒤 다시 붙여 넣으세요. 휴대폰에서 계속 어려우면 컴퓨터에서 같은 주소(samgoe-cc.or.kr/setup-sql.html)로 하시면 됩니다.
